# 系统流程说明

## 岗位匹配流程

1. 学生录入个人信息、专业、技能、意向城市和最低薪资。
2. 系统读取岗位数据库。
3. 系统根据硬性条件过滤岗位。
4. 系统计算专业、技能、薪资、城市等维度匹配分。
5. 系统输出 Top N 推荐岗位。
6. 学生查看岗位推荐结果和风险提示。

## 多 Offer 决策流程

1. 学生录入多个 Offer 信息。
2. 学生设置薪资、成长性、稳定性、兴趣匹配度、福利等指标权重。
3. 系统对 Offer 指标进行标准化处理。
4. 系统执行加权评分。
5. 系统生成 Offer 排名。
6. 系统输出最优 Offer 建议和风险提示。
7. 学生保留最终决策权。
