# 系统设计说明

系统采用四层架构：

1. 用户层：学生通过页面录入个人信息、偏好权重、Offer 信息，并查看推荐结果。
2. 应用层：处理用户请求，调用岗位匹配、Offer 决策等业务服务。
3. 模型层：封装岗位匹配模型、多 Offer 加权评分模型、风险识别规则。
4. 数据层：存储用户、岗位、Offer、权重、匹配结果和决策结果。

## 数据库核心表

1. student_user：学生用户表
2. job_position：岗位信息表
3. user_weight：用户权重表
4. student_offer：Offer 信息表
5. match_result：岗位匹配结果表
6. decision_result：Offer 决策结果表

## 核心模块

1. 用户信息与偏好模块
2. 岗位匹配推荐模块
3. 多 Offer 决策模块
4. 风险提示模块
5. 结果展示模块
