# 需求说明

本系统面向大学生求职场景，解决两个核心决策问题：

1. 在大量招聘岗位中，如何筛选出适合投递的岗位。
2. 在获得多个 Offer 后，如何科学选择最优 Offer。

## 核心用户

在校大学生、应届毕业生、实习求职者。

## 核心功能

1. 用户信息管理
2. 求职偏好与权重设置
3. 岗位数据管理
4. 岗位智能匹配推荐
5. 多 Offer 决策评分
6. 风险提示
7. 决策结果展示

## 核心决策方法

1. 岗位匹配：硬性条件过滤 + 多维度加权评分
2. Offer 决策：指标标准化 + 用户权重 + 综合评分排序
3. 风险提示：基于规则库识别高加班、低稳定、低薪资、通勤压力等风险
