# job-dss-system
# 项目说明

本项目是“大学生求职岗位匹配与多 Offer 决策支持系统”，用于决策支持系统课程实验演示。

## 核心目标

实现一个可运行的 DSS 原型系统，覆盖：

1. 学生用户信息与择业偏好录入
2. 岗位数据管理与岗位智能匹配推荐
3. 多 Offer 录入、加权评分、排序与风险提示
4. 决策结果保存与展示

## 技术栈

- backend: Spring Boot 3 + Maven + MySQL
- frontend: Vue 3 + Vite + Element Plus + ECharts
- database: MySQL
- API 返回 JSON
- 使用模拟数据，不需要真实爬虫

## DSS 设计要求

系统需要体现：

- 数据库：用户表、岗位表、Offer 表、权重表、匹配结果表、决策结果表
- 模型库：岗位匹配模型、多 Offer 加权评分模型、AHP/简化权重模型
- 知识库/规则库：高加班、低稳定、低薪资、通勤过长等风险规则
- 人机界面：用户录入、结果展示、推荐解释

## MVP 功能范围

必须实现：

1. 学生信息录入/修改
2. 权重设置
3. 岗位推荐 Top N
4. Offer 录入
5. Offer 综合评分排序
6. 风险提示
7. 演示用初始化数据
8. README 说明如何启动项目

暂不实现：

- 真实招聘平台爬虫
- 复杂权限系统
- 在线部署
- 支付、短信、邮件等功能

## 开发规范

- 后端接口统一以 /api 开头
- 前端页面保持简洁，适合课程答辩演示
- 所有核心算法要写注释，方便报告和答辩说明
- 每完成一个模块后，运行测试或启动项目验证
- 不要引入过于复杂的依赖
